KIDS PLATFORM
=============

Run it
------
1. Unzip the whole package to any folder (a USB stick works too).
2. Double-click  start.bat
3. The game opens in your browser. Leave the black window open while playing;
   close it to stop the game.

Nothing needs installing: it only uses what Windows already has. If Windows
warns about start.bat the first time ("Windows protected your PC"), choose
More info -> Run anyway (copying the folder over USB instead of downloading
the zip avoids the warning).

Plug in the USB steering wheel before starting, turn it a little so the
browser notices it, and pick a vehicle with the wheel (or the arrow keys).
To check the wheel or set it up (pedals as buttons or axes, steering the
other way round), press the gear icon in the garage (or O) and choose
"Volante" - it shows what the wheel sends and calibrates it in a minute,
and lets you give the wheel's buttons jobs (siren, camera, mute, accelerate,
brake...), as many buttons as you like for each.
Use Microsoft Edge or Google Chrome. If it runs slowly, open the garage's
gear icon (or press O) and set Graphics to Low.

Keys
----
A D / arrows steer, W / S gas and brake, C camera, R back to the start,
E siren, O settings, Esc garage.

Em portugues
------------
1. Descomprima o pacote todo para uma pasta (ou uma pen USB).
2. Faca duplo clique em  start.bat
3. O jogo abre no navegador. Deixe a janela preta aberta enquanto joga;
   feche-a para parar o jogo.

Nao e preciso instalar nada. Ligue o volante USB antes de arrancar, rode-o um
pouco para o navegador o detetar, e escolha o veiculo com o volante.
Use o Microsoft Edge ou o Google Chrome.

The game folder holds the built game; VERSION.txt says which version this is.
